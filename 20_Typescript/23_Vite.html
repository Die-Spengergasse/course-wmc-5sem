Was macht ein Bundler?

Ein Bundler beginnt bei einer Datei, dem Einstiegspunkt (entry point). Er folgt allen import-Anweisungen und bereitet jedes Modul für den Browser vor. Die Beispiele sind echte Ausgaben von Vite für die App ViteDemo.


      

    

  


  
  

    
index.html ist der Einstiegspunkt

    
Vite beginnt bei index.html und folgt allen Importen. So entsteht der Modulgraph (module graph):
      Er zeigt, welche Datei welche andere braucht.

    

      
      
      
      
      
    

    

    

    

    

  


  
  

    
Der Dev-Server: npm run dev

    
Der Dev-Server (Entwicklungs-Server) übersetzt jede Datei erst, wenn der Browser sie anfordert.
      Verfolge die Requests wie im Reiter Network der Entwicklertools (F12).

Der Build: npm run build

    
Ein Webserver im Internet soll nicht jedes Modul einzeln ausliefern. npm run build erzeugt deshalb
      wenige, fertige Dateien im Ordner dist.
